Privacidad · Quiz Bible

Política de privacidad

Esta política describe el estado actual del MVP web de Quiz Bible, incluido el progreso que se conserva localmente en el navegador.

Aplicación: Quiz BibleResponsable: Neuronova Apps · Gabriel BerrospiActualización: 14 de agosto de 2026

Estado actual

Quiz Bible ofrece un primer quiz web funcional con seis preguntas. La experiencia incluye selección de respuesta, comprobación, explicación educativa, referencia bíblica, puntuación, restauración del avance y reinicio. Todavía no existen cuentas, ranking ni sincronización remota.

Datos y acceso

El quiz puede utilizarse sin crear una cuenta y sin proporcionar nombre, correo electrónico, teléfono u otros datos identificativos. Las respuestas se procesan en el navegador para calcular el estado y la puntuación del recorrido.

Progreso local

Quiz Bible utiliza localStorage con la clave quizbible-progress-v1 para conservar en este navegador la versión del formato, la pregunta actual, las respuestas ya comprobadas y si el recorrido fue completado. La puntuación no se acepta como un valor independiente almacenado: se vuelve a calcular a partir de las respuestas válidas del banco actual.

Validación del estado

Al restaurar el progreso, la aplicación comprueba la versión del formato, los identificadores de las preguntas, las opciones existentes y el orden secuencial del recorrido. Los datos desconocidos, incompatibles o posteriores a una interrupción del orden válido se descartan. Si localStorage no está disponible, el quiz puede seguir funcionando durante la sesión sin persistencia.

Banco de preguntas y transmisión

Las preguntas se cargan como contenido estático desde el propio sitio. Las respuestas elegidas y el progreso local no se envían a una base de datos propia de Quiz Bible. Quiz Bible tampoco vende esos datos ni los utiliza para crear perfiles publicitarios propios.

Eliminación

El botón Reiniciar progreso elimina el estado guardado por Quiz Bible y vuelve a la primera pregunta. También puede eliminarse borrando los datos del sitio desde la configuración del navegador.

Servicios futuros

Si más adelante se incorporan cuentas, sincronización, ranking, analítica, publicidad, servicios en nube u otros SDK que impliquen tratamiento adicional de datos, esta política se actualizará antes de habilitar esas funciones y se detallará qué información se conserva, con qué finalidad y cómo puede eliminarse.

Servicios externos

El sitio se publica mediante GitHub Pages. El acceso al repositorio de GitHub, al ecosistema Neuronova Apps o a otros enlaces externos queda sujeto a las políticas de esos servicios.
